# Store - Django Store

Интернет-магазин на Django.

## Функции

- 🛒 **Корзина товаров** - добавление и удаление товаров
- 🔍 **Поиск товаров** - поиск по названию и описанию
- 📊 **Сортировка** - по цене и названию
- 👤 **Профиль пользователя** - редактирование профиля с аватаром
- 📷 **Загрузка изображений** - загрузка аватара пользователя
- 📄 **Пагинация** - разделение товаров на страницы
- 🏪 **Два каталога товаров** - основной и второй каталог

## Установка и запуск

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
cd Store
python manage.py migrate
python manage.py runserver
```

## 🔑 Функции приложения

### 📄 Главная страница (`home`)
- Привлекательный hero блок
- Показ 4 преимуществ магазина
- Превью популярных товаров
- Статистика магазина
- Кнопка для регистрации

### 🛍️ Каталог товаров (`product_list`)
- Показ всех товаров в виде карточек
- Поиск по названию и описанию товаров
- Сортировка по цене (возрастание/убывание)
- Сортировка по названию товара
- Кнопка "Добавить в корзину"

### 📋 Страница товара (`product_detail`)
- Полная информация о товаре
- Большое изображение товара
- Цена и описание
- Кнопка добавления в корзину

### 🛒 Корзина (`view_cart`)
- Список всех товаров в корзине
- Количество и цена каждого товара
- Общая сумма
- Удаление товаров из корзины
- Кнопка оформления покупки

### 👤 Регистрация (`register`)
- Красивая форма регистрации
- Поле для логина
- Поле для email
- Поле для имени и фамилии
- Проверка на уникальность email
- Валидация пароля
- Автоматический вход после регистрации

### 🔐 Вход (`login`)
- Красивая форма входа
- Логин (username)
- Пароль
- Защита CSRF токеном
- Перенаправление на предыдущую страницу

## 👨‍💻 Разработка

### Запуск в режиме разработки
```bash
python manage.py runserver
```

### Создание миграций после изменения моделей
```bash
python manage.py makemigrations
python manage.py migrate
```

Перейдите на `http://localhost:8000/admin` и введите данные суперпользователя
